# Skill Report — 스킬 충돌 검사 2026-10-27

`python3 scripts/skill-conflicts.py`로 처음 검사한 결과다. 아래 "판단"은 사람이 후보를 읽고 정한 내용이고, 그 밑의 "검사 결과"는 스크립트 출력을 그대로 붙였다.

## 판단

| 후보 | 판단 | 처리 |
|---|---|---|
| 코드 리뷰 스킬 6개 (`/code-review`, engineering `code-review`, caveman-review, ponytail-review, superpowers 리뷰 2개, review-council) | 실제 충돌. 리뷰를 부탁하면 어느 것이 불릴지 정해져 있지 않다 | 기존 기준대로 `/code-review`를 먼저 쓰고, 큰 변경에만 review-council을 쓴다. caveman-review와 ponytail-review는 설명이 가장 많이 겹친다(0.44) |
| 같은 이름 `competitive-brief` (product-management, marketing) | 실제 충돌 | 제품 기획 단계는 product-management, 홍보 단계는 marketing-skills `competitor-profiling`을 쓴다. marketing(Anthropic) 것은 쓰지 않는다 |
| 같은 이름 `seo-audit` (marketing, marketing-skills) | 실제 충돌 | marketing-skills `seo-audit`을 쓴다 |
| 브레인스토밍 (superpowers, product-management) | 실제 충돌 | 제품 아이디어는 product-management, 기능 설계 직전은 superpowers `brainstorming`을 쓴다 |
| 성과 보고 (marketing `performance-report` ↔ product-management `metrics-review`) | 겹침 | 출시 후 첫 지표 검토 때 비교한다 |
| 고객 조사 (marketing-skills `customer-research` ↔ product-management `synthesize-research`) | 겹침 | 조사 결과 정리는 product-management, 리뷰·커뮤니티 수집은 marketing-skills를 쓴다 |
| 디자인 5개 스킬 | 이미 알고 있던 충돌 | Skill Playbook 기준을 그대로 따른다 |
| 배포 주제에 superpowers `writing-skills`, aws `prompt-library` | 오탐 | 설명에 deploy라는 단어가 있을 뿐이다 |
| **세션 시작 때 지시를 넣는 훅 5개** (caveman, impeccable, ponytail, aws-startup-advisor, superpowers) | 실제 위험 | 아래 참고 |
| **메시지마다 지시를 넣는 훅 2개** (caveman, ponytail) | 실제 위험 | 둘 다 "짧게, 작게"라는 같은 방향이라 서로 부딪히지는 않는다. 다만 fluent-korean 출력 스타일과는 반대 방향이다 |

### 훅에서 새로 찾은 것

- **aws-startup-advisor:** 상태는 "보류"인데도 세션마다 "스타트업 관점으로 모든 답변을 맞추라"는 지시를 넣는다. 쓰지 않는 플러그인이 모든 답변에 영향을 준다. claude.ai에서 이 플러그인을 끄는 것을 제안한다.
- **superpowers:** 세션마다 "스킬이 조금이라도 맞으면 반드시 불러라"는 지시를 넣는다. 스킬이 많을수록 이 지시 때문에 엉뚱한 스킬이 불릴 가능성이 커진다. 스킬 수를 줄여야 하는 이유가 하나 더 생겼다.

## 4. 부르지 않아도 작동하는 지시

메시지나 세션마다 지시를 넣는 훅과 출력 스타일이다. 같은 시점에 여러 개가 있으면 지시가 서로 부딪힐 수 있다.

| 시점 | 플러그인 (훅 수) | 지시를 넣는 시점인가 |
|---|---|---|
| PostToolUse | impeccable (1) | 아니오 |
| PreToolUse | review-council (1) | 아니오 |
| SessionEnd | caveman (1) | 아니오 |
| SessionStart | caveman (1), impeccable (1), ponytail (1), aws-startup-advisor (1), superpowers (1) | 예, 여러 개 겹침 |
| Stop | impeccable (1) | 아니오 |
| SubagentStart | caveman (1), ponytail (1) | 예, 여러 개 겹침 |
| UserPromptSubmit | caveman (1), ponytail (1) | 예, 여러 개 겹침 |
